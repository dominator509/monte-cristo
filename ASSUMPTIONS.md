# ASSUMPTIONS

Every assumption below was made because an input was UNKNOWN or because a fork had to be
pre-decided. Each has a verification step. None is silent.

| # | Assumption | Reason | Risk if wrong | How to verify | Blocks implementation |
|---|---|---|---|---|---|
| A-01 | macroquad 0.4.13 can hold 60 fps at 256x224 integer-scaled on 2017-class integrated graphics | It is the smallest pure-Rust option with no npm in the chain; the alternative (custom wgpu) is weeks of work | The shell misses the frame budget and EP-005 needs a renderer swap | `cargo bench --locked -p mc_core` plus the EP-005 M7 frame-budget smoke on the reference machine | No -- EP-005 declares a FALLBACK to a direct wgpu blit path |
| A-02 | Fixed-point Q16.16 is sufficient precision for all combat, poison, and positional maths | Floating point destroys cross-platform determinism, which is invariant INV-01 | Rounding artefacts in damage or interpolation | Property tests in EP-002 M4 over 10^6 random operations comparing against rational arithmetic | No |
| A-03 | postcard 1.0.10 is stable enough to be the save format across the 1.x line | It is compact, no_std-friendly, and versioned | A postcard change breaks old saves | The save-migration round-trip suite in EP-003 M6 pins the wire bytes with an insta snapshot | No |
| A-04 | A full-campaign golden tape replays headlessly in under 15 minutes | 40 hours of gameplay is roughly 8.6 million ticks; at 4 ms per 1000 ticks that is ~35 s of core time, and the margin is enormous | The tape becomes a nightly job instead of a per-commit gate | EP-007 M8 times the replay and records it in the bench report | No |
| A-05 | 102 bestiary entries and 118 maps are the right content scale for a 36-40 hour campaign | Derived from Chrono Trigger and Final Fantasy VI content densities | The game is too short or too thin | `cargo run -p mc_tools -- report bestiary` and the EP-007 content-coverage report | No |
| A-06 | The operator's host can build for all three targets (Linux native, Windows via mingw, macOS) | Stated in PREFLIGHT 1.4 | EP-009 cannot produce the full artifact set | `sh scripts/probes/graphics_stack.sh` and EP-009 M2 cross-build | Yes for EP-009 only |
| A-07 | cargo-fuzz nightly (nightly-2025-01-15) remains installable | Fuzzing requires nightly; production never does | EP-006 loses its fuzz gate | `rustup toolchain list` in EP-006 M1 | No -- EP-006 declares a FALLBACK to `arbitrary`-driven proptest corpora on stable |
| A-08 | No dependency in the tree carries a licence outside MIT, Apache-2.0, BSD-2, BSD-3, Zlib, Unicode-3.0 | Business constraint | A licence violation ships | `sh scripts/dependency-audit.sh` (cargo-deny licence policy) on every verify | Yes -- it is STOP condition (c) |
| A-09 | The Windows and macOS builds produce identical state hashes to Linux for the same seed and tape | Required by LF-09; fixed point and sorted iteration should guarantee it | Cross-platform determinism claim is false | EP-009 M4 replays the golden tape on each produced artifact and compares hashes | Yes for EP-009 |
| A-10 | 210,000 words of dialogue can be authored as RON without a bespoke editor | The string table is externalised and validated by the bake | Authoring is slower than planned | The EP-003 M3 schema and the `validate` command on the shipped Act I content | No |
| A-11 | The reference machine identifier in MC_REFERENCE_MACHINE is stable for the life of the run | Performance budgets are only meaningful against a fixed machine | Budget failures cannot be attributed | The bench report records it; EP-010 M5 compares it to the value recorded at EP-001 | No |
| A-12 | Content advisory requirements (the game depicts suicide and the death of a child) are satisfied by a dismissible pre-title screen that is remembered | Faithfulness to the novel is a product requirement; a warning is the minimum responsible treatment | Players are ambushed by the material | EP-005 M9 acceptance criterion and its e2e assertion | No |
| A-13 | No database is needed at any point | Single-player offline with file-based saves | A late requirement forces a storage engine | EP-003 acceptance: the save and content layers satisfy every persistence requirement in SPEC-002 | No |
| A-14 | The operator will run CI on a self-hosted runner that simply invokes scripts/verify.sh | Avoids a hosted CI account as a dependency of the ship gate | CI configuration drifts from the real gate | EP-001 M8 asserts the CI config contains no gate logic of its own | No |
